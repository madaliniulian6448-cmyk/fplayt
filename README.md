# FPlayT Live Players

Interfață live pentru serverul FiveM FPlayT.

## Funcții
- număr jucători online
- listă ID / nume / ping
- căutare după ID sau nume
- refresh automat la 1 secundă
- responsive pentru telefon

## GitHub Pages
Activează GitHub Pages din:
Settings -> Pages -> Deploy from a branch -> main / root

## Notă
Pagina încearcă endpoint-ul public Cfx.re pentru join code `ajyydz`. Dacă Cfx.re blochează cererile browser-side prin CORS/rate-limit, va fi necesar un proxy serverless (Cloudflare Worker / Vercel / Netlify Function).
